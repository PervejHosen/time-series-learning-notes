# Time Series: Learning Notes

My study notebooks from working through time series courses and tutorials. These are **learning notes, not original projects**: most of the code and explanations follow the course material listed below.

For my own end-to-end forecasting project, see **[Store Sales Forecasting](https://github.com/PervejHosen/store-sales-forecasting)**.

| Notebook | Topic | Based on |
|---|---|---|
| `Kaggle_Linear_Regression_With_Time_Series.ipynb` | Trend, seasonality and lag features with linear regression and XGBoost | [Kaggle Learn: Time Series](https://www.kaggle.com/learn/time-series) |
| `Time_series_analysis_in_python.ipynb` | Moving averages, exponential smoothing, SARIMA, feature-based models | [mlcourse.ai Topic 9, Part 1](https://mlcourse.ai/book/topic09/topic9_part1_time_series_python.html) by Dmitry Sergeyev |
| `Time_series_with_facebook_prophet.ipynb` | Forecasting with Prophet | [mlcourse.ai Topic 9, Part 2](https://mlcourse.ai/book/topic09/topic9_part2_facebook_prophet.html) by Egor Polusmak |
| `Time_Series_forecasting_(End_to_End_Projects).ipynb` | ARIMA, SARIMAX, Holt-Winters, auto_arima | Tutorial walkthroughs |
| `Rosmann_sales_competition.ipynb` | First exploration of the Rossmann data | [Kaggle: Rossmann Store Sales](https://www.kaggle.com/competitions/rossmann-store-sales) |

The notebooks read data from my Google Drive, so they won't run as they are. The datasets come from the sources above.

All credit for the course content goes to its authors.
